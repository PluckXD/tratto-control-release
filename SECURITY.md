# Security policy

This public repository is not a support channel and must not receive product
vulnerability details, credentials, customer identifiers, screenshots, logs,
or private infrastructure information.

Use GitHub's private vulnerability reporting for this repository. If sensitive
material is committed accidentally, do not open a public issue or pull request:
revoke the exposed material immediately and report it privately.

Release authorization is fail-closed. A missing reviewer, protection rule,
private carrier, provenance statement, or validated digest is a reason to stop
the release, never a reason to bypass a gate.
